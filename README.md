# 浙江科德亚洲班课程衔接图谱

**[打开网页查看知识点和对应关系](https://maxliu1979.github.io/Asia-Class-Curriculum-Atlas/)**

浙教版入学基础 → 高一沪版普高主课、英语基础与校本学科英语 → 高二高三 NCUK 学习。36 个知识点覆盖数学、物理、化学和英语，每科 9 条。另设初三下、高一上、高一下、高二上、高二下、高三上结束后六个转入入口，可从阶段建议直接跳到知识点。

三年主图覆盖六学期，每学期按数学、物理、化学、英语与学科英语、经济与商务、校内课程与发展展示建议任务、可复查的学习作品和知识点链接。另有 NCUK 2026–27 所查范围的 163 条规范定位，分属 9 个模块范围。学期顺序为教研编排建议，实际开课与报考安排由校区核定。

每条列教材或任务定位、衔接类型、NCUK 模块条目、原创诊断和复查建议。教材所在章节、校区实际授课和学生掌握分别确认。自研讲义逐页映射、当期开课及考试安排以校区核定材料为准。AOA 暂按 OxfordAQA 理解。

在浏览器打开 `index.html` 即可预览。采用静态网页，知识点数据与依据见 `data.js` 、`expanded.js`、`programme.js` 和 `module-index.js`。
